# 样例题：两数之和（本地题包演示）

## 题目描述

给定两个整数 $a$ 与 $b$，输出它们的和。

> 本题用于演示 ACM-Trainer v2.0 的**本地题包**格式：导入后即可在应用内提交代码、本机编译判题。

## 输入格式

一行两个整数 $a, b$（$-10^9 \le a, b \le 10^9$），用空格分隔。

## 输出格式

一行一个整数，表示 $a + b$。

## 样例

### 样例输入 1
```
1 2
```

### 样例输出 1
```
3
```

### 样例输入 2
```
-5 5
```

### 样例输出 2
```
0
```

## 数据范围

| 子任务 | 分值 | 限制 |
| ---- | ---- | ---- |
| 1 | 50 | $|a|, |b| \le 1000$ |
| 2 | 50 | $|a|, |b| \le 10^9$ |
