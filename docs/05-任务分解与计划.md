## 4. 执行顺序与规则
- 每完成一个任务：跑对应单测/集成测试 → 冒烟 → 更新本文档进度；
- GUI 运行验证（启动/联网同步/内嵌题面等）由用户在桌面执行（本开发环境无交互桌面）。

## 5. 风险与应对
| 风险 | 影响 | 应对 |
| ---- | ---- | ---- |
| ~~better-sqlite3 原生模块与 Electron 版本不匹配~~ | ~~M1/M2 阻塞~~ | ✅ **已解决**：better-sqlite3 **v13（Node-API 预编译，需 NAPI v10）**；Electron 33（Node 20.18，NAPI v9）加载即原生崩溃（0xC0000005）→ **升级 Electron 37**（Node 22.16，NAPI v10），Node（测试）与 Electron 均正常加载，无需本机 C++ 编译工具链 |
| npm 执行策略/网络问题（本机 npm.ps1 被禁） | 依赖安装受阻 | ✅ 已解决：使用 `npm.cmd` + 镜像源 + 工作区内缓存目录；npm 11 需 `npm install-scripts approve` 批准 install 脚本 |
| CF API 结构变动或网络不可达 | A2 受阻 | 解析层集中一处；失败返回错误码并保留缓存；提供「重试」 |
| 题面站点登录/弹窗复杂 | 使用体验 | v1 只做浏览；新窗口一律系统浏览器打开（v1.7 起题面为独立窗口，白名单内导航、外链仍走系统浏览器） |
| WebContentsView 在低版本 Electron 不可用 | A6 | 锁定 Electron ≥ 30（实际采用 37）；v1.7 起弃用内嵌、改独立窗口 |
| 单人开发进度风险 | 里程碑延期 | 按 P0 优先，P1/P2 后置；每里程碑可独立验收 |
| 评分公式主观性强 | 用户信任 | 公式透明展示 + 免责声明 + 单测锁定行为 |
