# 06 用户验收指引 —— ACM-Trainer

- 版本：v1.0
- 说明：首次运行与验收操作指引。配合 04-测试规范 §4 验收清单使用。
- 日常使用请见 **docs/09-使用手册.md**（含界面截图与 FAQ）。

## 1. 首次运行

```bash
cd C:\Workspace\acm-trainer
npm run dev
```

预期：弹出「ACM-Trainer」窗口（暗色主题），左侧 **11 个导航项**（首页 / 题库 / **📋 题单·计划** / 学习路径 / STL 速查 / 统计 / 笔记·错题 / 模板库 / 虚拟比赛 / 水平评估 / 设置；v1.0 为 7 项，v1.1–v1.8.2 陆续新增至 10 项，**v1.10 新增「📋 题单/计划」至 11 项**），顶栏显示当前页名，侧边栏底部显示 `pong @ 时间` 与版本号（当前 **v1.10.0**）。

## 2. 第一步：同步题库（需要联网）

1. 进入「题库」页；
2. 点击右上角 **同步题库**；
3. 等待进度条完成（拉取约 8000+ 道 CF 题，国内网络约 1–3 分钟）；
4. 完成后列表显示题目，顶部显示「最近同步」时间；
5. 断网测试：同步失败有错误提示，本地已缓存题目仍可浏览。

## 3. 按模块验收（04 §4 逐项勾选）

| 模块 | 快速验收路径 |
| ---- | ---- |
| 题库筛选 | 难度 1200–1800 + 标签 dp + 状态「未练习」，点重置恢复 |
| 题面 | 点题目行 → 详情抽屉 →「📖 打开题面」→ 弹出独立窗口显示 CF 页面（v1.7 起）|
| 记录练习 | 抽屉内选择 AC/WA、填耗时、勾选错题 → 提交；列表「我的状态」列更新 |
| 统计 | 「统计」页查看总览卡片与三张图表 |
| 笔记 | 「笔记」页 → 新建笔记 → 输入 Markdown（含 ```cpp 代码块）→ 预览高亮；停顿 2s 自动保存 |
| 错题 | 记录时勾选过「错题」的记录出现在「笔记」页错题 Tab |
| 模板库 | 新建分类模板（如 图论/Dijkstra）→ 复制按钮 → 粘贴验证 |
| 虚拟比赛 | 创建（5 题、1200–1800）→ 生成题单 → 创建并开始 → 计时倒计时 → 对每题记录 AC/WA → 结束 → 查看结果（AC 数 + 总罚时） |
| 水平评估 | 有练习+比赛数据后进入「水平评估」→ 查看 Rating/称号/分解项 → 「重新计算并记录」→ 趋势图出现首点 |
| 首页 | 概览卡片、当前水平、最近练习列表 |

## 4. 验收判定

- 04 §4 清单全部勾选 → 验收通过；
- 发现缺陷：记录操作步骤与现象，反馈后修复并回归；
- 验收通过后可执行 `npm run build:win` 生成安装包（A13，可选）。

## 5. 常见问题

| 现象 | 处理 |
| ---- | ---- |
| 启动报 node_modules 相关错误 | 重新执行 `npm install`（先 `npm install-scripts approve electron better-sqlite3 esbuild vue-demi`） |
| 同步失败/超时 | 检查网络；应用会自动重试 1 次；本地缓存不受影响 |
| 题面空白 | 确认能访问 codeforces.com（可先开代理）；视图仅允许 codeforces 域名 |
| 数据保存在哪 | `%APPDATA%\acm-trainer\acm-trainer.db`（userData 目录） |

## 6. 洛谷数据源验收（v1.1，FR-8）

首次同步耗时约 3–5 分钟（326 页分页拉取），请预留时间并保持联网：

| 步骤 | 操作 | 预期 |
| ---- | ---- | ---- |
| 1 | 题库页 →「同步洛谷」按钮 | 进度条显示「第 N/326 页」，完成后 toast「洛谷同步完成：新增 X 道」 |
| 2 | 数据源切换「洛谷」 | 列表约 1.6 万道 P 题；题号列为 Pxxxx；难度列显示洛谷评级（入门/普及-…）与颜色 |
| 3 | 洛谷难度下拉 + 标签筛选 + 关键字（如 P1000） | 筛选生效；切回「Codeforces/全部」无残留难度条件 |
| 4 | 点洛谷题 →「📖 打开题面」 | 弹出独立窗口显示 luogu.com.cn 页面，可独立关闭 |
| 5 | 洛谷题记录练习（AC/WA、勾错题） | 「我的状态」更新；错题 Tab 与统计（标签分布）联动 |
| 6 | 反向确认 | 「虚拟比赛」组卷与「水平评估」列表不含洛谷题（仅 CF） |
| 7 | 数据备份 | 「设置」页导出 JSON 应包含洛谷题（problems.source='luogu'），导入后可恢复 |

常见报错对照：LUOGU_FETCH_FAILED（网络/HTTP 异常，重试或检查代理）；LUOGU_PARSE_FAILED（页面结构变化，需升级应用）；中途失败不会损坏已入库数据，可重新同步（幂等）。

常见口径说明：多标签题目会同时计入多个知识点；难题 = CF rating≥1600 或洛谷难度≥5 的 AC；推荐集 = 前置达标且自身未达标（docs/03 §12.1）。

| 3 | 切到「🔁 今日复习」Tab | 汇总**所有题单**中 `到期日 ≤ 今天` 的条目（**逾期也算**）；每题显示所属题单、题号、题目、难度、档位/到期日，并有 **困难 / 一般 / 轻松 / 题面** 四个按钮 |
| 4 | 点「**一般**」 | 档位 **+1**（第 1 档 → 第 2 档），下次日期按新档位间隔顺延（3 天后） |
| 5 | 点「**困难**」 | 档位 **−1**；在第 1 档时点「困难」仍是第 1 档（**最低 1 档**） |
| 6 | 点「**轻松**」 | 档位 **+2**（跳一档）；在第 5/6 档时点「轻松」**封顶第 6 档**（60 天） |
| 7 | 走完 6 档后 | 文案显示 `第 6/6 档 · 已巩固` |
| 8 | 暂无到期条目时打开「今日复习」 | 显示空态文案（不是空白页） |
| 9 | 回题单列表 | 每份题单显示各自的**待复习数** |

### 15.4 训练计划（FR-28，日历排期）

| 步骤 | 操作 | 预期 |
| ---- | ---- | ---- |
| 1 | 「🗓️ 训练计划」Tab → 新建计划 | 表单含：题单（或「不用题单，自动抽题」+ 抽题数量）、每日题量、目标日期、赛道预设、CF rating 区间、**每周休息日多选**、是否排除已练 |
| 2 | 选题单 + 每日题量 = 3 → 创建 | 计划列表出现该计划，显示 `完成/总数`；右侧**日历按日期分组**，每个可用日排 3 题 |
| 3 | 勾选「每周休息日」中的某一天 | 该星期几**不出现在排期中**，任务自动落到下一个可用日 |
| 4 | 点某日期上的「标记这天没空」并填原因（如「期中考试」） | 该日期显示**日期 + 原因**；**其后未完成任务整体顺延**（**总题量不变、已完成的任务不动**） |
| 5 | 日历中点任务可看题面 / 勾选打卡 | 打卡后显示完成态，计划 `完成/总数` 同步变化 |
| 6 | 目标日期设置了较早日期（排不完） | 出现 **overflow 提示**（「有 N 题超出目标日期」）——**不硬塞进最后一天、也不静默丢题**；放宽目标日期或调大每日题量即可排完 |
| 7 | 点「重新排期」 | 按当前参数重排；**已完成任务保持不动**，只重排未完成任务 |
| 8 | 删除计划 | 计划的全部任务与「没空日」一并删除，题单本身不受影响 |
