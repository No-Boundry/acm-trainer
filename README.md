面向个人 ACM/ICPC 学习与训练的**本地桌面应用**（Electron 37 + Vue 3 + TypeScript + SQLite）。当前版本 **v1.20.0**，规格驱动开发（SDD），规格文档见 [docs/](docs/)。

- 📚 **题库**：Codeforces（约 1.1 万题）、洛谷 P 题（约 1.6 万题）与**力扣算法题（3930 道）三数据源**（合计 31,764 题），按难度/知识点/状态/关键字筛选（**v1.20 起筛选项只有「知识点」一个维度，原来的 6 个标签大类已并入知识点**），**排序规则**（按难度按各题源自己的难度列、按题号数字序、空难度恒排最后、全部视图按题源分组）
- 🧠 **知识点筛选（v1.20：唯一筛选维度）**：**70 个知识点**按 L0–L6 分层展示，带掌握度色点与「已练/已 AC」题数，多选并集筛题（已接入力扣中文标签）；原先只在筛选界面裸露的概念类标签（`搜索` / `递推` / `树链剖分` / `数位 DP` / `莫队` / `cdq 分治` 等 **32 个**）已并入 **22 个知识点**，赛事 / 来源 / 年份类标签（`ICPC`、`洛谷原创`、各省省选、年份…）不再出现在筛选界面（题目行仍展示来源）；**标签已中英统一（v1.18）**：同一概念的英文标签（`greedy` / `dsu`）在入库时即归并为中文（`贪心` / `并查集`），搜 `greedy` 与搜 `贪心` 等价
- 🎯 **首页推荐习题（v1.14；v1.16 起与题库页共用题源筛选）**：固定「**已练习**」「**未练习**」两栏（默认各 8 条）—— 已练习默认按**遗忘曲线**排序（越久没碰、AC 越少越靠前，紧急度 ≥ 0.5 标「该复习了」），未练习默认**优先「练习中」知识点、组内 AC 数升序**；两栏都支持知识点/标签筛选，点条目直达题库（`?q=<题号>`），条数与排序在设置页「首页推荐习题」面板可调（1–30，改完立刻生效）；**推荐区上方多一行题源切换（全部 / Codeforces / 洛谷 / 力扣），与题库页是同一个状态，在哪边切另一边都跟着变**
- 🏷️ **已练习标签（v1.14）**：每个练过的知识点标签直接显示 **`已AC数/题数`**（如 `贪心 9/9`），未 AC 的标签另列计数，**点 chip 即筛选推荐**；技能树标签按钮同样显示题库题数与 ✅ 已 AC 数，题库无题的标签画虚线
- 🕘 **刷题记录（v1.19）**：首页按**打开题面的时间倒序**列出你打开过的题（题号/题名/难度/时间），同一道题只占一行、多次打开显示「打开 N 次」；点条目重新打开题面，「清空记录」不影响题库与练习记录；已纳入备份 / 恢复
- 🗺️ **学习路径（技能树）**：内置知识图谱（依赖连线、五档掌握度、推荐下一步），一键跳题库练习（**支持单个知识点直达**：卡片「📚」快捷按钮或详情面板按钮）；**v1.14 起关联标签可手动勾选**，只把自己挑的标签带去题库；**v1.20 起节点详情新增「✓ 确定全选 / ✕ 取消全选」与「⊘ 排除已 AC / ✓ 只看已 AC」三态过滤**（跳题库时把 `ac` 条件带过去，补题 / 复习不用再手动重勾）；**5 个国内比赛赛道**（蓝桥杯 / 天梯赛 GPLT / ICPC·CCPC / NOIP·CSP-S / 牛客多校）—— 赛制说明、推荐难度、**必达进度条**、「按赛道去题库练习」
- 📋 **题单**：**三种建法**（题库勾选 / 粘贴题号识别 / 按知识点+难度生成），题单内记录完成状态、备注与复习进度
- 🔁 **题单内间隔复习**：**1 / 3 / 7 / 14 / 30 / 60 天**阶梯，勾选完成自动进入第 1 档；「今日复习」跨题单汇总（逾期也算），反馈 **困难退一档 / 一般进一档 / 轻松跳一档**
- 🗓️ **训练计划**：日历排期式 —— 每日题量、每周休息日、**标记「这天没空」后未完成任务自动顺延**、任务打卡、**超出目标日期的题量明确提示（不硬塞、不丢题）**
- 📝 **练习记录与统计**：结果/耗时/错题标记，ECharts 趋势与知识点分布，**难度分布（按题源）**
- 📓 **笔记与错题本**：Markdown 编辑（代码高亮、Tab 缩进、自动保存）
- 🧩 **模板库**：算法模板分类管理，一键复制
- 📘 **STL 速查**：内置 35 条竞赛 STL 参考资料（容器/算法/复杂度/坑点，**含各容器的初始化与清空写法 + 「初始化与清空速查对照」**，可搜索、一键复制代码、跳转 cppreference）
- ⚔️ **虚拟比赛**：按难度/**知识点组卷（v1.20 起创建向导使用同一套知识点选择器：点节点 = 勾选它全部关联标签）**、限时训练、ACM 罚时计分、结果回看
- 🏅 **水平评估**：综合分（练习+比赛，权重可配）＋ 独立的洛谷练习水平与**力扣练习水平**，历史趋势
- 🔗 **题面**：用 **Edge 浏览器**打开原站页面（CF / 洛谷 / 力扣；v1.8 起不再内嵌网页题面）

## 快速开始

1. 安装：运行 `dist\ACM-Trainer-1.20.0-setup.exe`（或免安装版 `dist\win-unpacked\ACM-Trainer.exe`）；
2. 首次进入「题库」页依次点 **同步题库**（Codeforces，1–3 分钟）、**同步洛谷**（3–5 分钟）、**同步力扣**（约 30–40 秒）；
3. 用「知识点筛选」按知识点练题（v1.20 起筛选区只有知识点一个维度；想补题就在学习路径节点详情点「⊘ 排除已 AC」再跳题库）→ 点「记录」写练习记录（排序可选「按难度 / 按题号 / 按 AC 数」，默认方向自动切换）；
4. 回「🏠 首页」看「**已练习标签**」（chip 显示 `已AC/题数`）与「**推荐习题**」两栏：已练习按遗忘曲线提醒该复习什么，未练习优先推「练习中」知识点的题；点标签 chip 可筛选，点条目直达题库（`?q=<题号>`）；
5. 到「学习路径」看掌握度与推荐，点「去题库练习」一键选中建议知识点，或用卡片右上角「📚」直达**单个知识点**；**打开知识点详情可手动勾选/取消关联标签**，只练自己想练的那几个；**v1.20 起详情面板还有「✓ 确定全选 / ✕ 取消全选」与「⊘ 排除已 AC / ✓ 只看已 AC」两个按钮**（AC 三态：不过滤 → 排除已 AC → 只看已 AC）；也可**切换国内比赛赛道**看必达进度；
6. 到「📋 题单/计划」把要练的题组成题单（题库勾选 / 粘贴题号 / 按知识点生成），用「🔁 今日复习」按间隔复习；
7. 到「🗓️ 训练计划」按每日题量排上日历，标记没空日自动顺延，做完就地打卡；
8. 到「⚙️ 设置 → 首页推荐习题」调两栏的**排序方式**与**条数（1–30）**，回首页立即生效；
9. 到「统计 → 难度分布（按题源）」看各难度段的已练/AC 情况。

## 环境备注（Windows）

- npm.ps1 被执行策略禁止时使用 `npm.cmd`；
- npm 11 首次安装需 `npm install-scripts approve better-sqlite3 electron esbuild vue-demi`；
- SQLite 使用 better-sqlite3 v13（Node-API 预编译，无需本机 C++ 工具链）；
- 题面统一由 **Edge 浏览器**打开；未检测到 Edge 时回退系统默认浏览器；
- GUI 自动化脚本启动时会剔除环境变量 `ELECTRON_RUN_AS_NODE`（该变量会让 electron.exe 退化为纯 Node，无法创建窗口）。

## 版本说明

### v1.20.0
本版把**题库筛选收敛成「知识点」一个维度**（6 个标签大类 Tab 与裸标签列表整体移除），把真正属于算法的概念类标签补进知识点；同一套知识点选择器同步到**虚拟比赛创建页**；**学习路径**节点详情新增「确定/取消全选」与「排除已 AC / 只看已 AC」三态过滤；另新增**发布操作手册**与**安装包自检**。**无新增数据表、无新增 IPC 通道、0 个设置项**（`problems:list` 入参只多一个可选 `ac`），覆盖安装即可。

- **为什么砍大类**：真实库 **516 个标签里有 332 个不被任何知识点覆盖**，其中绝大多数是赛事 / 来源 / 年份类（`Special Judge` 2818 题、`ICPC` 2176、`洛谷原创` 1383、各省省选 1208、2022–2026 等年份、`USACO`…）。更关键的是**同一个「贪心」有两条入口**：知识点里是节点、「算法基础」大类里又是标签，两边互不相通，最后表现为「找不到东西」。
- **怎么处置**：概念类标签（`搜索`、`递推`、`数位 DP`、`树链剖分`、`莫队`、`cdq 分治` 等）**补进 22 个知识点、共 32 个标签**（技能树标签引用 229 → **261**，节点数仍是 **70**，旧 id 一个不改）；赛事 / 来源 / 年份类标签**不物理删库**（题库每行仍要展示来源，删了不可逆），只是不再出现在筛选界面。单节点标签上限由 6 放宽到 **10**，改后实际最大 **8**（`graph` 图论入门、`graph_conn` 连通性与割点桥）。另补 5 组中英别名（`gcd` → 最大公约数、`NTT` → 快速数论变换等）。
- **共用知识点选择器**：新增 `src/renderer/src/components/common/KnowledgePicker.vue`（受控组件；「已选中」= 该节点全部标签都在已选集合里），题库页与虚拟比赛创建页（紧凑模式 `show-summary=false` / `show-tip=false`）共用；比赛组卷点知识点 = 把它全部关联标签并入 `tags`，**后端 `contest:generate` 零改动**。
- **已 AC 过滤**：学习路径节点详情「⊘ 排除已 AC / ✓ 只看已 AC」三态循环（默认不过滤 → 排除已 AC → 只看已 AC → 回到不过滤，切节点复位），跳题库时带 `?ac=notac` / `?ac=ac`，题库页顶部出现「题目状态：排除已 AC ✕」条件条；后端 `ProblemFilter.ac` 用 `EXISTS / NOT EXISTS (SELECT 1 FROM practice_records ... status = 'AC')` 判定 —— 与「已练习（有没有提交记录）」不同，**只提交过 WA 的题在「排除已 AC」里仍保留**（补题要的正是这些）。
- **发布流程固化**：新增 [docs/11-发布操作手册.md](docs/11-发布操作手册.md)（9 章：一页速查 / 发版准备 / 全量自检 / 构建与 GUI 验收 / 打包与 asar 自检 / 推送与 GitHub Release / 回滚 / 常见问题 / 发版检查表）与 `npm run verify:asar`（解出 asar 后与 `out/` 逐文件 sha256 比对、校验 asar 内版本号、抽查新功能关键串）。

测试 **552/552（50 文件）**、`verify:gui` **131/131**（新增 12 项）、`verify:smoke` **33/33**、`tsc` + `vue-tsc` **0 错误**；新增截图 4 张（`02-problems-knowledge.png`、`03-knowledge-filtered.png`、`04c-ac-filter.png`、`14c-contest-knowledge.png`）、删除 2 张旧命名截图，配图合计 **33 张**；`npm run docs:shots` 改为只覆盖脚本自己负责的 26 张、不再整目录删除（保留人工补拍的验收图）；安装包 `dist\ACM-Trainer-1.20.0-setup.exe` **89.80MB**，`npm run verify:asar` 四项全 PASS（asar ↔ `out/` 6/6 一致）。

### v1.19.0
本版做两件事：**把学习路径从 54 个知识点拆成 70 个**（单个知识点最多 6 个标签，不再出现「图论入门」一次勾 18 个标签），**首页新增「刷题记录」**（按打开题面的时间倒序记录你打开过的题）。新增 1 张表 `problem_views`、2 个 IPC 通道、**0 个设置项**；技能树是代码内静态数据，**无数据迁移**，覆盖安装即可（`problem_views` 由 `CREATE TABLE IF NOT EXISTS` 自动创建）。

- **为什么拆**：改前 54 个节点共引用 231 个标签、平均 4.28 个，但**有 12 个节点挂着 7 个以上标签**（`graph` 图论入门 **18** 个、`segtree` 线段树 **12** 个、`math_basic` 基础数学 **11** 个、`sort` 排序 **11** 个…）。后果：① 点一个节点等于一次勾十几个标签，题库「已选」条被塞满，筛出的题量与该节点统计的题量对不上；②「学到哪儿了」说不清 —— 拓扑排序会了、割点桥没碰，进度只能算一整个 18 标签节点的掌握度。
- **怎么拆**：**只拆不改 id**（题单 `knowledge_ids`、训练计划、5 个赛道的 `focus`/`required` 都按字符串 id 存，改 id 会让用户已有数据静默失效）。新增 16 个节点：`bezout` 同余与裴蜀、`prime` 素数筛法、`sort_adv` 线性与特殊排序、`heuristic_search` 启发式搜索、`graph_conn` 连通性与割点桥、`euler` 欧拉路、`graph_extra` 平面图与哈密顿、`sparse_block` ST 表与分块、`balanced_tree` 平衡树、`lichao_kd` 李超树与 K-D 树、`ac_auto` AC 自动机、`flow_impl` 最大流实现、`minimax` 极大极小与零和博弈、`shortest_adv` 特殊最短路、`geo_adv` 计算几何进阶、`dp_seq` 序列 DP；另把 `回溯` 移到「暴力与剪枝」、`抽屉原理` 移到「组合数学」。每个新节点都带中文简介（≥25 字）、`dependsOn` 前置与 ≤6 个标签。

本版把**同一概念的中英文标签统一成一个标签**：CF 题的 `greedy` 与洛谷/力扣题的 `贪心` 现在入库时就归并为 `贪心`（`dsu` → `并查集`、`dp` → `动态规划`…）。**无新增数据表、无新增 IPC 通道、无新增设置项、无新字段**，覆盖安装即可（旧库首次启动自动迁移一次，幂等）。

### v1.17.0
本版把题库页的**标签筛选从交集改为并集**，并按**命中标签数降序**排序（命中越多越靠前，命中数相同再按你选的排序方式）。**无新增数据表、无新增 IPC 通道、无新增设置项**，覆盖安装即可。

- **之前的现象**：标签是交集语义（题目必须同时带全部已选标签）。技能树里有些知识点节点关联多个标签（如「贪心」挂 `greedy` + `贪心`），点一个节点就等于同时勾上多个标签，常直接筛出 **0 题** —— 与「点节点 = 勾选它关联的全部标签」的预期相反。
- **并集语义**：`buildWhere()` 的 `filter.tags` 分支由 `GROUP BY pt.problem_id HAVING COUNT(DISTINCT t.id) = <已选标签数>` 改为子查询并集 `p.id IN (SELECT pt.problem_id FROM problem_tags pt JOIN tags t ON t.id = pt.tag_id WHERE t.name IN (@tag0, …))`；未知标签在并集下被忽略，不再把列表清空。
- **排序**：新增私有函数 `matchedTagsOrderPrefix(tags?: string[])`，未选标签时返回**空串**（ORDER BY 与旧版逐字符一致），有标签时返回命中数子查询作为 ORDER BY 前缀，拼到 `buildOrderSql()` 的 4 个 return 分支最前。它复用 `buildWhere()` 注册的 `@tagN`，因此**必须先 `buildWhere()` 再拼 ORDER BY**。
- **界面**：命中数可见化 —— 已选标签 ≥ 2 个时，题目行标签区末尾显示琥珀色 `命中 N/M` 角标（`N` 命中数 / `M` 已选数），「已选」条提示「取并集 · 命中标签越多越靠前」；只选 1 个标签时两者都不出现。
- **未动**：题单自动抽题用的 `filter.tagsAny` 本来就是并集，本版未改动；`problem_tags` 表结构与数据不变，**无数据迁移**。

### v1.14.1

**v1.14.1 是性能补丁版**：只修性能，**无新功能、无新增数据表、无新增 IPC 通道、无新增设置项**，覆盖安装即可。
修的是用户反馈的「**首页跳转题库有明显卡顿**」+「**启动速度明显变慢**」——两者同一根因：首页推荐要取整个题库，
旧实现用分页接口一页页翻（3 万题要翻 **159 页**，每行还带标签聚合 / `EXISTS` 已练习 / 最近状态 **3 个相关子查询**），

这 9 秒会把所有页面切换与 IPC 一起堵住，所以用户看到的是「启动慢 + 跳题库卡」。
修复：新增 `ProblemsRepo.leanAll()`（单条精简 SQL 取全库）+ 三级缓存（题库 / 标签统计 / 推荐结果，数据一变缓存键就变、随机排序不缓存）+ 首页 `requestAnimationFrame` 先出统计卡片；
顺带修掉 `RecordsRepo.list()` 的 **200 条静默截断**（技能掌握度 / 水平评估 / 首页已练习段 / 组卷候选 4 处调用点改用新增的 `records.all()`）。
实测：首页统计卡片 **13984 → 787 ms**、`recommend:get` **12498 → 33 ms**、题库→首页 **12802 → 157 ms**；
新增 `npm run verify:perf` 性能自查（复制真实库副本测量，不写真实数据）。测试 **458/458（43 文件）**。
